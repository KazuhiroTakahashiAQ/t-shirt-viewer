          操作方法

          • マウスホイール: 拡大・縮小 / 左ドラッグ・右ドラッグ・中ドラッグ: 画面移動
          • 左クリック: 図形を選択してプロパティを表示 / 右クリック: メニュー
          • ダブルクリック (図形以外): 用紙範囲を表示 / 左下の選択欄: モデルとレイアウトの切替
          • F: 全体表示 / P: 用紙範囲 / W: 窓拡大 / BackSpace: 前画面 / + −: 拡大・縮小
          • D: 距離計測 / A: 面積計測 (クリックで点を指定、ダブルクリックまたは Enter で確定、Esc で終了)
          • Ctrl+F: 文字検索 / Ctrl+PageUp・PageDown (または Alt+PageUp・PageDown): カレントシート切替
          • 計測時は端点・中点・中心に自動でスナップします (Shift を押している間は無効)
