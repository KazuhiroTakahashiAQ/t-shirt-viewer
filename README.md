# T-Shirt Viewer

`.tfs` 形式の図面ファイルと部品ライブラリ (サブセットライブラリ: `.NCP` / `.MDB` / `.USR`) をブラウザで表示するビューアです。公開仕様やライブラリが存在しないため、サンプルファイルを解析してファイル形式を独自に読み解いています (解析結果は [docs/FORMAT.md](docs/FORMAT.md)。解析の過程で分かったことのメモと既知の課題は `docs/FINDINGS.md`・`docs/KNOWN_ISSUES.md` として手元にだけ置き、git では管理していません)。

- 公開版: https://kazuhirotakahashiaq.github.io/t-shirt-viewer/ (main への push で GitHub Actions が自動でビルド・配信。アプリとしてインストールも可)
- インストール不要のブラウザアプリ (ファイルはローカルで解析され、外部へ送信されません)
- 32bit / 64bit 両方のセクション表形式に対応 (ファイル形式バージョン 3.4〜3.6 で確認)
- 手元のサンプル 119 図面と部品ライブラリ 2 種 (`resources/` に置く。git 管理外) がすべて読込可能 (`npm run check`)

## 使い方

```sh
npm install
npm run dev        # http://localhost:5180 を開く (ポートは固定。使用中なら起動しない)
```

1. ［ファイル］－［開く］で `.tfs` を選ぶか、画面にドロップします。フォルダーごとのドロップや［フォルダを開く］も使えます。
2. 図枠などの外部参照ファイル (別のファイルに描かれた枠や表題欄) を一緒に開くと合成表示します。後から図枠ファイルだけ追加しても、表示中の図面に反映されます。
3. URL で開くこともできます: `http://localhost:5180/?file=resources/plan.tfs&file=resources/frame.tfs`
4. 最近開いた図面は［ファイル］メニューと初期画面の「最近開いたファイル」(最大 10 件) から開き直せます (Chrome・Edge)。一緒に開いた図枠などの外部参照ファイルも合わせて開きます。
   - ブラウザーは Web ページにファイルの場所 (フルパス) を教えないため、場所は記録できません。［フォルダを開く］やフォルダのドロップで開いた図面だけ、そのフォルダからのパス (例: `案件/図面/1F 平面図.tfs`) を表示します。
   - 記録するのはファイルへの参照だけで、図面の中身はブラウザーに保存しません。初めて開くときやブラウザーを開き直した後は、読み取ってよいかをブラウザーが確認します。ファイルを移動・削除していると開けず、一覧から外れます。
   - 一覧は［ファイル］－［最近開いたファイルの一覧を消去］で消せます。

### 画面構成

元の CAD の画面に合わせた構成です。ボタン・切替・シートタブ・プロパティの項目名などにマウスを乗せると、その働きと用語 (シート・レイアウト・カレントシート・縮尺・FL など) の説明を表示します。

- メニューバー: ファイル / 表示 / ツール / 3D / 部品 / ヘルプ
- ツールバー: 開く・印刷、全体・用紙・窓拡大・前画面・拡大・縮小、選択・距離・面積・検索、3D・断面・断面線・画面分割、表示切替 (カラー・単色指定・黒背景・線幅・文字・補助・用紙枠)
- 左パネル: シート一覧 / レイヤ一覧 / 図面情報 / 文字検索 / 部品ライブラリ
- 作図領域の左下: レイアウトの切替 (モデル / 各レイアウト) とシートタブ、その下にカレントシート名と縮尺
- 右パネル: プロパティ (選択した図形の種別・シート・レイヤ・色・線種・線幅・寸法・文字など) と計測結果
- ステータスバー: 操作ガイド、カーソル座標、用紙サイズ、縮尺、表示倍率

ツールバー (上)・左パネル・右パネル・シートタブ (下)・ステータスバー (下) は［表示］メニューで表示・非表示を切り替えられます (ブラウザーに記憶)。幅の狭い画面では右パネルの代わりに左パネルの「情報」タブにプロパティと計測結果を表示します。

### 操作

| 操作 | 内容 |
| --- | --- |
| 左クリック | 図形を選択してプロパティを表示 (配管・寸法などはオブジェクト単位で選択) |
| 左 / 中 / 右ドラッグ | 画面移動 |
| ホイール / ピンチ | 拡大縮小 |
| 右クリック | メニュー (全体表示・用紙範囲・窓拡大・前画面・計測など) |
| ダブルクリック (図形以外) | 用紙範囲を表示 |
| `F` / `P` | 全体表示 / 用紙範囲 |
| `W` | 窓拡大 (ドラッグで範囲指定) |
| `BackSpace` | 前画面 |
| `+` / `-` | 拡大 / 縮小 |
| `D` / `A` | 距離計測 / 面積計測 (端点・中点・中心にスナップ。Shift で解除。ダブルクリックか Enter で確定) |
| `Ctrl+F` | 文字検索 (Enter で次、Shift+Enter で前) |
| `Ctrl+PageUp` / `Ctrl+PageDown` (または `Alt+PageUp` / `Alt+PageDown`) | カレントシート切替 (ブラウザーによっては Ctrl の組み合わせがタブ切替になるため Alt でも可) |
| `Ctrl+O` / `Ctrl+P` | 開く / 印刷 |
| `Esc` | ツール終了・選択解除 |

用語は元の CAD に合わせています。「シート」は縮尺を持つ透明な作図面 (ベース、建築図、設備図…)、「レイアウト」は印刷用の用紙にモデルの一部をビューポートで配置したもの、「レイヤ」はシート内の図形の分類 (通り芯、壁…) です。

単色指定: 元の CAD のシートには「単色指定」(そのシートの図形をすべて 1 色で表示する設定) と「グレー表示」があり、元の CAD と同じくカレントシート以外をその色で表示します。多くのシートにこの設定がある図面は、全体が白や灰色に見えます (開いたときにステータスバーで案内します)。ツールバーの「単色指定」(［表示］メニューの「シートの単色指定・グレー表示を反映」) を外すと、どのシートも図形の本来の色で表示します。

シート一覧・シートタブ: チェックで表示切替、クリックでカレントシート、ダブルクリックでそのシートの範囲を表示、右クリックで「このシートのみ表示」などのメニュー。初期の表示状態はファイルに保存された状態で、元の CAD と同じくカレントシートを含むレイアウトを開きます。単色指定のシートはカレントシートにすると図形の色で表示されます。

レイヤ一覧: 元の CAD のレイヤ (図形の分類。基本・建築・電気・空調・衛生のグループ) をグループごとに表示します。チェックまたはクリックで表示・非表示、グループのチェックでまとめて切り替え、右クリックで「このレイヤのみ表示」「このグループのみ表示」などのメニュー。「選択図形のレイヤのみ」で選択中の図形と同じレイヤだけを、「選択図形のレイヤを非表示」で同じレイヤの図形をまとめて隠します (例: 給水管を 1 本選んで給水管だけを見る / 寸法線を 1 つ選んで寸法線を隠す)。図形を右クリックすると、その図形を選択してメニューに同じ項目を出します (本体の平面・3D・立面・断面。別ウィンドウには右クリックメニューはありません)。プロパティ欄の「このレイヤを非表示」も同じです。「図形有のみ」は元の CAD の［図形有］と同じく、図形のあるレイヤだけを一覧に出します。レイヤの表示状態は平面・レイアウト・3D・立面・断面・印刷・SVG 保存・文字検索に反映されます。

レイアウト: 左下の選択欄で切り替えます。ビューポートはモデルの指定範囲を (回転・縮尺を含めて) 切り抜いて配置し、表示シートの指定と非表示レイヤを反映します。文字関数 (`$(工事名称)` など) は表示中のレイアウトの値で置き換えます。

出力: ［ファイル］－［印刷］は表示中のモデルまたはレイアウトの用紙範囲を用紙サイズどおりに印刷します (ブラウザの「PDF に保存」で PDF 化可能)。SVG 保存は表示範囲、PNG 保存は表示中の画面です。

### 3D 表示・立面・断面

元の CAD の 3D 表示・クイック断面に相当する機能です (閲覧のみ)。図面に保存されている高さ・寸法から立体を組み立てます。

- ［3D］(ツールバー) で平面と 3D を並べて表示します。［3D］メニューまたはツールバーの「画面分割」で、平面＋3D / 3D のみ / 4 分割 (平面・3D・正面・右側面) / 2 面図展開 / 4 面図展開 を切り替えます。各ウィンドウ左上の選択欄で、そのウィンドウの表示 (3D / 正面 / 背面 / 右側面 / 左側面) を変えられます。
- ウィンドウの並べ替え・大きさ: ウィンドウの境界線をドラッグすると大きさを変えられます (ダブルクリックで半分ずつに戻す。大きさはブラウザーに記憶)。ウィンドウの見出し (ボタン以外の部分) をドラッグして別のウィンドウの上で離すと、2 つの位置を入れ替えます (ドラッグ中に Esc で中止)。［3D］メニューの「ウィンドウの並び・大きさを元に戻す」で最初の状態に戻ります。別ウィンドウでも同じ操作ができ、上部の「並びを戻す」で戻します。
- 3D ウィンドウ: 左ドラッグで回転、右・中ドラッグ (または Shift+左ドラッグ) で移動、ホイールで拡大縮小。ダブルクリックした図形を回転の中心にします。開いた直後は真上から見た「平面」の視点 (平面図と同じ向き) です。「視点…」で等角 (右手前・左手前・右奥・左奥から)・平面・正面・背面・右側面・左側面 (正面は図面の手前 = 下側から見た向き)、「透視」で透視投影と平行投影を切り替えます。
- 立面・断面ウィンドウ: 平行投影で、シート基準高さの階 (例 `2F(4000)`) を点線で表示します。カーソル位置の高さを `高さ 6,850 (2F FL+2,850)` のようにステータスバーに表示します。
- クイック断面:［断面］で平面上の範囲を対角 2 点で指定すると、範囲内を切り取った断面を正面・右側面などに表示します (展開は［3D］メニューで 2 面図 / 4 面図を選択)。［断面線］は 2 点で切断線を、3 点目で見る方向と奥行きを指定し、斜めの断面も表示できます。指定した範囲は平面に水色の枠と「正面」の矢印で表示します。範囲を消すには、ツールバーまたは断面ウィンドウの［断面解除］、平面の右クリックメニュー、Esc キー (図形を選択していないとき) を使います。「平面のみ」に戻したときや断面ウィンドウをすべて閉じたときも自動で解除します。
- 3D の図形をクリックすると平面の図形も選択され、プロパティに 3D 形状・サイズ (例 `65A (外径 76.3)`、`600 × 600`)・高さ (`FL+2,850` など、シート基準高さからの値) を表示します。平面で選択した図形は 3D でも強調表示されます。プロパティの「3D で表示」でその図形に寄ります。
- ［3D］メニューのオプション: シート基準高さを反映 (階あり / 階なし)、平面図を重ねる、建築部材を半透明 (3D ウィンドウの「建築半透明」でも切替)、機器・部品を 5 面図からの推定形状で表示 (3D ウィンドウの「推定形状」でも切替。下記)、3D も断面範囲で切り取る、2D と 3D の表示位置を連動・拡大率を連動 (それぞれ選択可。平面を動かす・拡大縮小すると 3D・立面・断面が同じ場所・同じ縮尺で追従し、3D 側を動かすと平面が追従。立面・断面ウィンドウは横方向の位置だけを平面とやり取りします)。平面でレイアウト (用紙) を表示している間は連動しません。各 3D ウィンドウの「2D連動」は位置と拡大率をまとめて切り替えます。
- 連動のずれ調整: 3D を斜めから見ると、平面図と同じ点を中心にしても見えている範囲が合いません。連動中に各ウィンドウの「ずれ調整」を押すと、そのウィンドウだけを動かせる (平面図は動かない) 状態になり、もう一度押すと、そのときの平面図とのずれ (位置と拡大率) を保ったまま連動します。「ずれ解除」で元に戻します。別ウィンドウでも同じ操作ができます。ずれは図面を開き直すと解除されます。
- ［3D を別ウィンドウで表示］(各ウィンドウの ⧉) で 3D・立面・断面を別のブラウザーウィンドウに表示します (元の CAD の「フレーム外」)。シートの表示状態・断面範囲・選択・連動は元のウィンドウと同期します。

3D になるもの:

- 配管・ダクト (空調 0x500・衛生 0x600 など): 保存されている 3D の芯線に沿って、丸 (配管・スパイラルダクト・フレキ) または角 (角ダクト) の断面で表示します。継手は中心から各接続口へ向けた形で表示します。
- バルブ: 図面に保存された寸法 (芯から接続口までの長さ L1・L2、接続口の外径 D1、ハンドル高さ H1、ハンドル径 H2) で、接続口までの円柱・弁棒・ハンドルを表示します (本体の形は図面にないため円柱で代用)。単線表示の記号として描かれたバルブは、記号の大きさに合わせた寸法が保存されているため、プロパティに「記号の大きさに合わせた寸法」と表示します。
- ダクト機器 (消音チャンバー・ボックス): 保存された幅・奥行き・高さの箱で表示します。その他の形鋼・ボルト・基礎などは形の情報が解読できていないため、3D の基準線だけを表示します。
- 縮尺の違うシート (例: 1/50 の図面の中の 1/10 詳細図) は座標が拡大されて保存されているため、配管の太さなどにも同じ倍率を掛け、プロパティの高さは実寸 (FL) で表示します。
- 建築部材 (柱・壁・梁・スラブ・天井など): 保存されている外形を押し出して表示します。サンプルの IFC と柱の位置・寸法・高さが一致することを確認しています。
- IFC などから取り込まれた 3D の面・線 (グループ図形の 3 次元折れ線)。
- 機器・器具などの部品: 立体形状は部品ライブラリ側にあり図面に含まれないため、図面に保存された部品の外形の箱 (幅・奥行き・高さ) で表示します。電気部品は保存された幅・奥行き・高さが平面の外形と合う場合に箱で表示します。高さの情報がない部品 (吹出しシンボルなどの記号) は、取付高さに平面の形だけを線で表示します。
- 推定形状 (5 面図から): 「推定形状」をオンにすると、外形の箱で表示している部品 (空調・衛生) を、図面に入っている部品の 5 面図 (平面・正面・背面・右側面・左側面の 2D の図) から作った形で表示します。各図の外形をその図を見た方向に押し出し、すべてが重なる部分だけを残します (外形の箱の内側)。このビューアが推定した形で、元の CAD の 3D 表示 (ライブラリの 3D データ) とは異なります。どの図にも現れないくぼみや穴は再現されず、図に描かれた本体以外の線 (配管の接続部など) も形に含まれます。プロパティの「推定に使った図」に使った図を表示します。サンプル 280 図面の部品定義 161 種すべてで形を作れ、そのうち 147 種は形の外寸が外形の箱と一致しました。電気部品と、5 面図がない・外形が閉じていない部品は箱のままです。

### 部品ライブラリ

部品データフォルダー (元の CAD の「サブセットライブラリのインポート処理」で使うもの) を［部品］－［部品ライブラリを開く］で選ぶか、ドロップします。

- 分類ツリーと型番・名称の絞込み、仕様 (能力・寸法など)
- 平面・正面・背面・右側面・左側面の図形プレビューと 3D 形状 (ドラッグで回転)
- 「作図領域に表示」(またはダブルクリック) で 5 面図の配置で開き、選択・計測などが使えます
- カスタムデスク形式 (`.MDB` + `.USR` のみ) は形状を元の CAD 本体のストック部品から生成する仕組みのため、ファイルに図形がありません。登録されているアイコンのみ表示します。

静的ファイルとして配布する場合は `npm run build` で `dist/` を生成し、任意の Web サーバーに置いてください (Web Worker を使うため `file://` 直開きは不可)。3D 表示には WebGL2 に対応したブラウザーが必要です。

### アプリとしてインストール (PWA)

`npm run build` で作ったもの (`dist/`) を HTTPS (または localhost) で配信すると、インストールできるアプリ (PWA) として動きます。手元では `npm run build && npm run preview` で http://localhost:5181 に配信できます。開発サーバー (`npm run dev`、http://localhost:5180) でもインストールはできますが、オフライン用の仕組みは働きません。インストールしたアプリはアドレス (ポート番号を含む) ごとに別のアプリになるため、ポートは固定しています。

- インストール: ［ヘルプ］－［アプリとしてインストール…］(ブラウザーがインストールを提案できるときだけ表示)、またはブラウザーのアドレスバーのインストールボタン。デスクトップやスタートメニューから専用のウィンドウで起動できます。
- オフライン: 一度開くと、ビューア本体 (ページ・スクリプト・アイコン) をブラウザーに保存し、ネットワークがなくても起動して図面を開けます。図面ファイルはこれまでどおり手元のファイルを読むだけで、保存・送信はしません。
- OS から開く (Chrome・Edge): インストール後、エクスプローラー / Finder で `.tfs` (部品ライブラリは `.NCP` / `.MDB` / `.USR`) を右クリックし「プログラムから開く」でこのアプリを選ぶと、そのファイルを開きます。すでにウィンドウが開いていれば、そのウィンドウで開きます。
- 更新: 新しい版を配信すると、次に開いたときに裏で取得し、ステータスバーに「新しいバージョンがあります［更新］」を表示します。［更新］で読み込み直して新しい版に切り替えます (開いていた図面は閉じます)。押さなければ、ウィンドウをすべて閉じた後の次回起動で切り替わります。
- アプリの区別: マニフェストには `id` を書かず、開始ページ (`start_url`) のアドレスをアプリの ID にしています。`"id": "./"` はサイトの直下 (例: `https://<ユーザー>.github.io/`) と解釈されるため、同じサイトの別のフォルダーに置いた別の PWA と同じアプリとみなされてしまいます。
- 構成: `public/manifest.webmanifest` (アプリ名・アイコン・開けるファイルの種類)、`src/sw.ts` (Service Worker。保存するファイルの一覧と版はビルド時に `vite.config.ts` が書き込む)、`src/app/pwa.ts` (登録・インストール・OS からのファイル・更新通知)。アイコンの元絵は `public/icon.svg` と `public/icon-maskable.svg`。

## コマンドライン

```sh
npm run check                                   # resources/ 以下の全 .tfs (平面と 3D) と部品ライブラリを解析して結果を一覧表示
node scripts/tfs2svg.ts 図面.tfs 出力.svg         # SVG に変換 (外部参照は同じフォルダから解決)
node scripts/tfs2svg.ts 図面.tfs --layout レイアウト名 --width 3000 --color --black
```

`tfs2svg.ts` のオプション: `--layout current|model|名前|番号` (既定はカレントシートのレイアウト)、`--window paper|extents|x0,y0,x1,y1`、`--width px`、`--color`、`--black`、`--aux`、`--all-layers`

## 対応状況

表示できるもの:

- 線・連続線・円・円弧・楕円・楕円弧・スプライン・点
- 文字 (配置 9 種、回転、複数行、ＭＳ ゴシック等のフォント指定、用紙基準/実寸基準の文字高)
- 配管・ダクト・機器・寸法・引出線・部品などの複合オブジェクト (内部に保存された表示用図形を描画)
- シート (表示状態、単色指定、グレー表示、シートごとの縮尺)
- レイアウトとビューポート (回転・縮尺・切り抜き・表示シート指定・非表示レイヤ)、文字関数の展開
- 色 (図面の色番号 → RGB。1〜17 の基本色と AutoCAD ACI 系の拡張色)、線幅 (太線を太く表示)、線種 (ファイル内定義と、マニュアルの見本から比率を測った組込線種 2〜14・20〜26 など)
- 外部参照 (図枠ファイルの合成)
- 埋め込みラスタ画像 (BMP/DIB・JPEG・PNG)
- OLE 埋め込みオブジェクトのうち、画像を貼り付けたもの (EMF / WMF / DIB の表示データを合成して表示)
- 部品ライブラリ (NCP の 5 面図と 3D 形状、MDB の分類・仕様、カスタムデスクのアイコン)
- 3D・立面・断面 (配管・ダクト・建築部材・取り込んだ 3D 図形・部品の外形)、シート基準高さ (階)

制限事項:

- 色・線種・線幅・シート表示の規則は、元の CAD の公式マニュアルと、各ファイルに元の CAD が保存している 800×800 プレビュー画像との照合で推定しています (プレビューとの画素一致率 92%)。色番号 18〜29 や 270 以降のユーザー定義色、組込線種の絶対寸法、二重線・波線などの特殊線種は近似または未対応です。
- シートの「弱表示」(線幅なし・点線表示) と、ファイルに保存されたレイヤの表示/非表示状態は格納場所が未特定のため反映していません (開いた時点では全レイヤを表示します)。外部参照で取り込んだ図枠のレイヤは一覧の切り替えの対象外です。
- レイアウトの用紙サイズは格納場所が未確認のため、ビューポートの配置範囲から求めています。
- OLE オブジェクトの表示データのうち、線・文字などのベクタ命令 (Excel の表を貼り付けた場合など) は未対応です。表示データを持たないもの (ファイルのパッケージ等) は枠とファイル名のみ表示します。
- 寸法・引出線は保存されている形状をそのまま描画します (元の CAD が表示時に再計算する関連付けは再現しません)。
- 複合オブジェクトの種別名の一部と、部品の仕様項目名は推定です (プロパティに「推定」と表示)。
- 3D の部品 (機器・器具) は外形の箱、または 5 面図からの推定形状で表示しています。図面の部品とライブラリの立体形状 (NCP の 3D モデル) の対応付けは未対応です (サンプル図面の部品は手元のライブラリと一致するものがありませんでした)。
- 3D の配管・ダクトの断面寸法は、呼び径 (A) からの外径換算、ダクトの幅×高さ、または平面図の幅から求めています。保温材の厚さ、冷媒管の 2 本組、継手の曲げ半径・フランジなどは再現しません。断面は切断面を塗りつぶさず、切り口が空洞に見えます。
- 編集・保存はできません (閲覧専用)。
- OS からファイルを開く機能 (PWA の file handling) と「最近開いたファイル」は Chrome・Edge のみです (File System Access API を使うため)。
